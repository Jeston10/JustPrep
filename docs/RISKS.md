# Risk register and watch-list

Every warning raised during planning, in one place, with the phase/PR where it bites and the exact mitigation. **Before starting any PR, read the rows tagged for that phase** (see `docs/MILESTONES.md` §13). A row is closed only by a PR that links it; "we'll remember" does not close a row.

Severity: **S1** = security or data loss · **S2** = outage / quota burn / broken build · **S3** = rework or quality regression.

## Closing a row

Reference the row in the PR body (`Closes R7`) and change **Status** to `Closed (PR n.m)` in the same PR. Rows marked *Standing* are never closed; they are re-checked at every phase exit (QUALITY §5).
